## 2. Project Title

Personal budget calculator 

---

## 3. Project Description

Program sederhana ini membantu pengguna untuk memantau pemasukan dan pengeluaran selama suatu periode.

---

## 4. Objectives
This project is designed to apply the following programming concepts:

- Variables
- Data types
- Operators
- Conditional statements
- Loops
- Algorithms
- JavaScript

---

## 5. Input

The program receives:

- Total pendapatan
- Beberapa pengeluaran
- Kategori pengeluaran
- Jumlah pengeluaran

---

## 6. Process

Program menghitung total pengeluaran dan sisa saldo

If the guess is:

- Sisa saldo ≥ 30% dari pendapatan → Baik
- Sisa saldo antara 10%–29% dari pendapatan → Perlu Perhatian
- Sisa saldo < 10% dari pendapatan → Kritis

---

## 7. Output
The program displays:

- Total pengeluaran 
- Sisa saldo pengguna
- Kondisi keuangan pengguna
- Ringkasan anggaran
